# หมากรุกไทย 2 วัน เล่นเป็น

เว็บไซต์สื่อการสอนหมากรุกไทยสำหรับเด็กประถมและผู้เริ่มต้นจากศูนย์  
ออกแบบเป็นหลักสูตร **2 วัน วันละ 6 ชั่วโมง** โดยใช้แนวคิด:

- Day 1: เดินเป็น
- Day 2: เล่นเป็น + เริ่มคิดเป็น
- เรียนทีละขั้น 26 บท: วันที่ 1 มี 14 บทพื้นฐาน และวันที่ 2 มี 12 บทต่อยอด; แยกการหงายเบี้ยและการฝึกเดินเบี้ยหงายเป็นคนละบท และเห็นตำแหน่งตั้งต้นเต็มกระดานหลังรู้จักหมากครบในบทที่ 10
- ทุกบทเริ่มจาก “รู้จัก → ดูวิธี → ลองเล่น” คำอธิบายสั้นทีละประโยคพร้อมลูกศรสาธิต ก่อนเข้าสู่แบบฝึก ไม่มีการข้ามขั้นด้วยการแตะหมากในหน้าอธิบาย
- บทเดินหมากสุ่มโจทย์เก็บดาวที่ต้องเดิน 1, 2 และ 3 ตา (เรือมากที่สุด 2 ตาก็เข้าถึงทุกช่องได้) คำนวณเส้นทางจริงเพื่อให้ทุกเป้าหมายไปถึงได้; เก็บครบ 3 ดาวแล้วฝึกเพิ่มได้จนกดยอมรับ
- ผ่านบทแล้วมีหน้าฉลองพร้อมหมากและดาวบนกระดาน ไม่ข้ามไปบทใหม่เอง มีปุ่มฝึกเพิ่มและบทถัดไป แผนที่บทเรียนแสดงลำดับสองวันพร้อมบทที่ปลดล็อก
- iPad ตั้งแต่ความกว้าง 700px ใช้กระดานใหญ่ด้านซ้ายและเนื้อหาด้านขวา ทั้งแนวตั้งและแนวนอน ขนาด/ตำแหน่งกระดานไม่เปลี่ยนตามขั้นหรือคำถาม; มือถือใช้พื้นที่กระดานคงที่เหนือแผงฝึกและปุ่มด้านล่าง
- บทแรกแสดงชื่อครบ 64 ช่อง (ก1–ญ8) ให้เรียนรู้ก่อน แล้วซ่อนชื่อกลางช่องเพื่อฝึกอ่านตำแหน่งจากช่องที่ตีกรอบ มี 3 ตัวเลือกต่อข้อ ต้องตอบถูกครบ 5 ตำแหน่งจึงยอมรับผ่านได้; ใช้คำใบ้ดูชื่อช่องและฝึกเพิ่มหลังครบเกณฑ์ได้
- บทฝึกเดินกำหนดเกณฑ์เดินถูกอย่างน้อย 3 ครั้ง พร้อมตัวนับ; เดินผิดไม่นับ และเมื่อครบยังฝึกต่อได้ไม่จำกัดจนกด “ยอมรับผ่านบทนี้”
- บทเบี้ยฝึกครบทั้งเดินตรง กินเฉียงซ้าย และกินเฉียงขวา; บทหงายเบี้ย รุก และหนีรุกมีโจทย์หลายตำแหน่งให้กดฝึกต่อ
- เน้นกิจกรรม Mini Game และการลงมือเล่น
- รองรับมือถือ แท็บเล็ต และจอโปรเจกเตอร์
- วันที่ 1 สอนการเดินหมากทีละชนิด ด้วยคำอธิบายสั้นและภารกิจทีละข้อ ก่อนแสดงกระดานตั้งต้นครบทั้งสองฝ่ายในบทที่ 10
- วันที่ 1 เรียงจากกระดาน → ขุน → เรือ → ม้า → เม็ด → โคน → เบี้ย → หงายเบี้ย → เดินเบี้ยหงาย → จัดหมาก → กิน → รุก → หนีรุก → รุกจน
- วันที่ 2 เรียงจากทบทวน → ป้องกัน → ปิดทางเรือ → กินตัวที่รุก → จดตาเดิน → เกมเสมอ → คิดก่อนเดิน → เล่นกับเพื่อน → เกมฝึก → มินิทัวร์นาเมนต์ → ประเมิน 5 ด่าน → พร้อมเล่นจริง; เก็บรายละเอียดกติกาแข่งขันไว้ในหัวข้อเสริมสำหรับครู
- บท “เดินแล้วจดหมาก” อยู่หลังจากเรียนรุกและรุกจน เพื่อให้ผู้เรียนรู้จักการเดินและความหมายของสัญลักษณ์ก่อนเริ่มบันทึก
- บทเสมอมี 4 คำถาม และมารยาทมี 3 คำถาม เรื่องการนับและการแข่งขันอยู่ในรายละเอียดสำหรับครู
- รุกจนวันแรกเปรียบเทียบกับ “ยังหนีได้” เท่านั้น เรื่อง “อับ” พร้อมภาพตำแหน่งที่อับจริงอยู่วันที่ 2
- เกมเต็มกระดานมีคู่ฝึกสีแดงเดินตอบ กำหนดให้เดินฝ่ายขาวถูกอย่างน้อย 6 ตา; ใช้หมากขาวได้ทุกตัว และตรวจความปลอดภัยของขุน
- เกมฝึกและมินิเกมมีใบบันทึกขาว–แดงอัตโนมัติ ใช้อักษรย่อตามกติกา 2569 พร้อม X / + / # คัดลอกหรือเก็บเป็นไฟล์ `.txt` ได้; มินิเกมเก็บบันทึกแต่ละเกมไว้ในไฟล์เดียวกันระหว่างฝึกบทนั้น
- ทุกบทมีหัวข้อเปิดอ่าน “กติกาสำคัญที่ใช้ในบทนี้” พร้อมลิงก์หน้าต้นฉบับ และปุ่ม “กติกา PDF” ด้านบนที่เปิดได้ตลอดเวลา
- มินิทัวร์นาเมนต์เป็นเกมสั้น 3 กระดานกับคู่ฝึกอย่างง่าย บันทึกผลและคะแนน; จบครบ 3 เกมและเดินถูกอย่างน้อย 3 ตา ไม่ต้องชนะทุกเกมจึงผ่านได้
- แบบประเมิน 5 ด่านให้ลงมือเดินม้า หงายเบี้ย กินด้วยเบี้ยหงาย ปิดรุก และรุกจนจริง ผ่านครบ 5 ด่านจึงกดยอมรับได้
- ทุกบทฝึกต่อหลังครบเกณฑ์ได้และไม่เลื่อนไปเอง ปุ่มในแผนสอนเปิดวันที่ 2 ได้เมื่อเรียนวันที่ 1 ครบ; ความคืบหน้ารุ่นเก่าถูกย้ายตามชื่อบทเดิม
- ใช้ภาพหมาก SVG ชุด Makruk Ada (ฝ่ายขาว–แดง)
- กระดานสีเหลืองทองสีเดียว เส้นแบ่งช่องเข้ม และพิกัดไทย ก ข ค ง จ ฉ ช ญ
- หลังผ่านขั้นอธิบาย เลือกหมากแล้วคลิก/แตะปลายทาง หรือใช้เมาส์ลากหมาก; ซ่อนดาวคำใบ้ได้โดยยังมีช่องเป้าหมายอยู่ในคำสั่งโจทย์
- เปิด/ปิด “แสดงตาเดิน” เพื่อดูจุดวงกลมหลังเลือกหมาก; แตะหมากเดิมหรือกด Esc เพื่อยกเลิกการเลือก
- ครูวาดลูกศรสีเขียวด้วยคลิกขวาค้างแล้วลาก หรือเลือก “วาดลูกศร” แล้วแตะช่องต้นทางและปลายทางบนมือถือได้
- วาดเส้นเดิมซ้ำเพื่อลบ ใช้ปุ่มย้อนกลับเพื่อลบเส้นล่าสุด หรือปุ่ม “ล้างลูกศร” เพื่อลบทั้งหมด; ปล่อยนอกกระดานหรือแตะช่องเดิมจะยกเลิกเฉพาะเส้นร่าง
- ใช้ Tab เข้ากระดาน ปุ่มลูกศรเลื่อนช่อง และ Enter/Space เพื่อเลือกหมากหรือปลายทาง
- ปุ่ม “เริ่มนับใหม่” เริ่มฝึกบทเดิมและล้างตัวนับ; บันทึกการผ่านบทเรียนในอุปกรณ์เมื่อกดยอมรับ
- เมนู “เพิ่มเติม” แสดงชื่อผู้จัดทำ “นายณัฐกมล สุนทรพิทักษ์” พร้อมปุ่มดูผู้จัดทำ/เครดิต กติกา PDF และแผนสอน; เครื่องมือกระดานอยู่ในปุ่มเฟือง ไม่บดบังช่องบนกระดาน

## รูปผู้จัดทำและเครดิต

ยังไม่ได้ใส่รูปบุคคลจริง จึงใช้พื้นที่ว่างที่มีสัญลักษณ์บุคคลในหน้าต่างผู้จัดทำโดยไม่โหลดไฟล์รูปที่ไม่มีอยู่ เมื่อได้รับรูป ให้เก็บไฟล์ใน `assets/images/` และแทน `#authorPhotoPlaceholder` ใน `index.html` ด้วยรูปพร้อมข้อความ `alt` ชื่อผู้จัดทำ

เครดิตภาพ Makruk Ada อ้างอิง PyChess Variants พร้อมใบอนุญาตต้นทาง ข้อมูลวิธีเดินอ้างอิง PyChess/GNU XBoard และ PDF 2569 มีลิขสิทธิ์แยกตามต้นฉบับ โค้ดระบบบทเรียนและกระดานอยู่ใน repository นี้ ไม่ได้อ้างว่าโครงการทั้งหมดใช้ใบอนุญาตเดียวกัน

## ไฟล์หลัก

- `index.html` — หน้าจอ กระดาน และระบบบทเรียน
- `day2-lessons.js` — เนื้อหาและโจทย์วันที่ 2
- `rules-lessons.js` — บทจัดหมาก จดหมาก เสมอ/นับปลายเกม มารยาทการแข่งขัน และเกร็ดกติกาพร้อมหน้าต้นฉบับทุกบท
- `learning-design.js` — ลำดับหลักสูตรล่าสุด คำอธิบายทีละขั้น และเส้นทางสุ่มโจทย์หลายตา
- `makruk-rules.js` — การเดิน การกิน การหงายเบี้ย ความปลอดภัยของขุน รุกจน และอับ
- `makruk-notation.js` — รูปแบบบันทึกตาเดินและการตรวจคำตอบการจดหมาก
- `assets/rules/makruk-rules-2569.pdf` — กติกาต้นฉบับ 36 หน้าที่ผู้ใช้ส่งมา เก็บโดยไม่แก้ไข พร้อมที่มาและสถานะลิขสิทธิ์ใน `assets/rules/SOURCE.md`
- `.github/workflows/pages.yml` — GitHub Pages deployment
- `tests/makruk-rules.test.cjs` — ตรวจการเดินและความถูกต้องของโจทย์ รวมพิกัด 64 ช่องและคำถามบทแรก
- `tests/makruk-notation.test.cjs` — ตรวจการจดหมากทั้งสองสี อักษรย่อทั้ง 7 ชนิด กิน รุก รุกจน หงาย และคำตอบรูปแบบต่าง ๆ
- `tests/rules-lessons.test.cjs` — ตรวจหลักสูตร 26 บท ตาตั้ง โจทย์จดหมาก และข้อมูลอ้างอิงกติกา
- `tests/learning-design.test.cjs` — ตรวจเส้นทางสุ่มจากทุกช่อง ทุกชนิดหมาก และทุกระดับ รวม 1,152 กรณี
- `tests/puzzle-flow.test.cjs` — ใช้ตัวจัดการเดินจริงตรวจว่าตาระหว่างทางยังเดินต่อได้ ให้ดาวเมื่อถึงเป้าหมายเท่านั้น และเปิด/ปิดคำใบ้ไม่เปลี่ยนเกณฑ์ผ่าน

ทดสอบด้วย `node tests/makruk-rules.test.cjs`, `node tests/makruk-notation.test.cjs`, `node tests/rules-lessons.test.cjs`, `node tests/learning-design.test.cjs` และ `node tests/puzzle-flow.test.cjs` (ไม่ต้องติดตั้งแพ็กเกจเพิ่ม) ระบบตรวจทั้งหมดอัตโนมัติก่อนเผยแพร่

## ขอบเขตเกมฝึก

คู่ฝึกสีแดงเป็นตัวช่วยเรียนเบื้องต้น ไม่ใช่ AI ระดับแข่งขัน ไม่มีการนับศักดิ์หมาก/ศักดิ์กระดาน จับเวลา หรือยุติเกมตามการเดินซ้ำ/ข้อเสนอเสมอโดยอัตโนมัติ บทปลายเกมสอนวิธีนับและมีคำถาม แต่ให้ครูช่วยนับบนกระดานจริง เกมฝึกสามารถยอมรับผ่านได้เมื่อครบเกณฑ์โดยไม่ต้องเล่นจนจบ

ใบบันทึกอัตโนมัติมีไว้เรียนรู้และย้อนดู ในการแข่งขันที่ต้องจดผู้เล่นต้องจดเองตามกติกา การยกเลิกการเลือกหมาก คำใบ้ และลูกศรครูเป็นเครื่องมือฝึก ไม่แทนกติกาจับแล้วเดินหรืออนุญาตให้รับคำแนะนำขณะแข่งขัน เว็บนี้ไม่ใช่ระบบแข่งขันที่ได้รับการรับรอง

เนื้อหาสอดแทรกเรียบเรียงใหม่จากกติกาการแข่งขันหมากรุกไทย พ.ศ. 2569 ที่ผู้ใช้ส่งมา โดยลิขสิทธิ์ PDF ยังคงเป็นของเจ้าของสิทธิ์ตามต้นฉบับ ไม่ใช่ส่วนหนึ่งของใบอนุญาตโค้ดหรือชุดภาพหมาก

อ้างอิงกติกาการเดิน: [PyChess Makruk](https://www.pychess.org/variants/makruk) และ [GNU XBoard Makruk rules](https://www.gnu.org/software/xboard/whats_new/rules/Makruk.html)

อ้างอิงแนวทางการสอน: [Chess.com Learn to Play](https://www.chess.com/lessons/learn-to-play/the-king) และทั้ง 12 บทที่ผู้ใช้ให้มา (ลิงก์ครบในหน้าเครดิต) ใช้แนวทางแนะนำ–สาธิต–ฝึก–ฉลอง ไม่คัดลอกโค้ด ภาพครู เสียง หรือกติกาที่ไม่มีในหมากรุกไทย เช่น castling และ en passant
