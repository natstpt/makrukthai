# สำหรับผู้เรียนและผู้สอน

ใช้ได้บนคอมพิวเตอร์ แท็บเล็ต และมือถือ ไม่ต้องสมัครหรือติดตั้งอะไร ความคืบหน้าและการตั้งค่าเก็บในเบราว์เซอร์ของเครื่องนั้น

## บทเรียน

แต่ละบทเรียงเป็น **รู้จัก → ดูวิธี → ลองเล่น** อ่านคำสอนในกล่องคำพูด ดูตัวอย่างบนกระดาน แล้วทำโจทย์เอง

| บท | เนื้อหา |
| --- | --- |
| 1–10 | รู้จักกระดาน · ขุน · เรือ · ม้า · เม็ด · โคน · เบี้ย · เบี้ยหงาย · เดินเบี้ยหงาย · จัดหมากก่อนเริ่ม |
| 11–15 | กินหมาก · รุก · หนีรุก · รุกจนหรือยัง · ทบทวนหมาก |
| 16–20 | การผูกหมาก · บังทางเรือ · กินหมากที่กำลังรุก · เดินแล้วจดหมาก · เกมเสมอ |
| 21–25 | คิดก่อนเดิน · เล่นกับเพื่อนอย่างสนุก · เกมฝึกเต็มกระดาน · เกมสั้น 3 รอบ · ลองทำ 5 ภารกิจ |
| 26–27 | การนับศักดิ์กระดาน · การนับศักดิ์หมาก |
| 28–32 | ไล่ปลายกระดาน ระดับ 1 (จนในตาเดียว) |
| 33–40 | ระดับ 2 (จนใน 2–5 ตา ขุนแดงหนีเอง) |
| 41–44 | ระดับ 3 ไล่ยาว (สูงสุด 16 ตา ขุนแดงหนีด้วยตารางท้ายเกม) |
| 45–46 | ระดับ 4 เป็นฝ่ายหนี (หนีจนนับเกินศักดิ์) |
| 47–55 | กลยุทธ์: ยึดกลางกระดาน · เปิดหมาก · ขุนปลอดภัย · คร่อม · กดหน้าขุน · เสียบ · กินหมากที่ติดขัด · เปิดรุก · โครงสร้างเบี้ย |
| 56–58 | เล่นกับ AI ระดับง่าย · กลาง · เซียน (เล่นจบ 1 เกมเพื่อผ่านบท) |
| 59 | เล่นจริง |

**วิธีเรียน**
- แถบล่างมี **เมนู · คำใบ้ · ย้อนกลับ · ถัดไป** ส่วนแถบสีส้มบอกความคืบหน้า
- แตะหมากแล้วแตะช่องปลายทาง หรือลากวางก็ได้
- ถ้าเดินผิด หมากจะเดินไปจริงก่อน แล้วขึ้น ✕ ฝ่ายแดงตอบให้เห็นว่าทำไมผิด จากนั้นกด **ลองใหม่**
- ผ่านบทแล้วเลือก **บทถัดไป** หรือ **ลองฝึกเพิ่ม** ได้ บทที่มีแบบฝึกมีโจทย์ 5 ชุดไม่ซ้ำกัน รวม 420 ข้อ
- บทไล่ปลายกระดานใช้ตำแหน่งจากตำรากลหมากรุกไทยของ นพ.ประกอบ บุญไทย ส่วนบทไล่ยาวและบทหนี ฝ่ายตรงข้ามเดินด้วยตารางท้ายเกมที่คำนวณครบทุกตำแหน่ง

**สำหรับผู้สอน**
- ในเมนูบทเรียน มุมขวาล่างมีปุ่ม **🔒 ปลดล็อกทุกบท** กดอีกครั้งเพื่อล็อกคืน ความคืบหน้าของผู้เรียนไม่เปลี่ยน
- ปุ่ม ⚙ มุมขวาบนรวมเครื่องมือทั้งหมด: เล่น 2 คน · เล่นกับ AI · ถอดหมาก · ตั้งหมาก · เพลง · เสียง · เครื่องมือกระดาน (วาดลูกศร) · การจด · กติกา · สีหมาก (ขาว–แดง หรือ ขาว–ดำ) · ผู้จัดทำ · เครดิต

## เล่นกับ AI

หน้า [/ai](https://natstpt.github.io/makrukthai/ai) ให้เลือกระดับและสีหมากก่อนเริ่ม และเปลี่ยนระดับระหว่างเกมไม่ได้

| ระดับ | ความแข็ง | วิธีคิด |
| --- | --- | --- |
| 👑 สุดยอดเซียน | แข็งที่สุด | AI รุ่นเต็ม (NNUE) คิดลึก 20 ชั้น ครั้งแรกต้องโหลด 48 MB |
| ⭐⭐⭐⭐⭐ ยอดเซียน | แข็งมาก | คิดลึก 20 ชั้น |
| ⭐⭐⭐⭐ เซียน | แข็ง | คิดลึก 12 ชั้น |
| ⭐⭐⭐ ฝึกฝน | กลาง ๆ | คิดลึก 8 ชั้น พลาดบ้างเล็กน้อย |
| ⭐⭐ มือใหม่ | ง่าย | คิดลึก 5 ชั้น |
| ⭐ เริ่มต้น | ง่ายที่สุด | คิดตาเดียวและพลาดบ่อย |

- **ระดับฝึกฝนขึ้นไป** เปิดหมากตามแผนแบบเซียน คือยึดกลางด้วยเบี้ย ง/จ แล้วพาม้า เม็ด และโคนขึ้นคุ้มกัน ระหว่างทางใช้ AI ตรวจว่าแต่ละตาปลอดภัย พอพ้นช่วงเปิดเกมแล้วจึงคิดเองเต็มที่
- แถบเหนือกระดานบอกว่า AI กำลังคิดถึงไหน
- เมื่อจบเกม หน้าสรุปผลแสดงความแม่นยำของทั้งสองฝ่าย จำนวนตาแต่ละระดับ และปุ่ม **▶ เริ่มวิเคราะห์**

## วิเคราะห์การเดิน

หลังจบเกมกับ AI โค้ชพาดูเกมทีละตา คล้ายหน้า Game Review ของเว็บหมากรุกสากล

- **ให้เกรดทุกตา** 9 ระดับ ตั้งแต่ แต้มเซียน · แต้มเด็ด · ดีที่สุด · ดีมาก · ดี · ยังไม่แม่น · พลาด · พลาดโอกาส จนถึง พลาดหนัก พร้อมเหตุผลภาษาง่าย ๆ เช่น "กินม้าที่ถูกปล่อยไว้ฟรี" หรือ "ปล่อยเรือให้ถูกกินฟรี" และมีแถบคะแนนกับกราฟความได้เปรียบตลอดเกม
- **ปุ่มเครื่องมือ**
  - **อันตราย** ดูว่า AI จะตอบอะไร (ลูกศรแดง)
  - **การเดินที่ดี** ดูตาที่ดีกว่า (ลูกศรเขียว) และกด ▶ ดูแนวต่อ ได้
  - **ลองใหม่** หาแต้มที่ดีกว่าเอง มีปุ่มใบ้และเฉลย
  - **ถัดไป** กระโดดไปจุดที่เกมเปลี่ยน
- **ทดลองเดิน** เดินหมากบนกระดานได้ทั้งสองฝ่าย ถ้าเดินต่างจากเกมจะเข้าแนวทดลอง (กรอบสีม่วง) engine ให้เกรดทุกตาที่ลอง ปุ่ม "การเดินที่ดี" ให้ AI คิดตำแหน่งนั้นใหม่แบบละเอียด และกด **↩ กลับเกมจริง** เพื่อกลับเกมเดิม
- **วิเคราะห์ละเอียด** คิดตาสำคัญซ้ำที่ความลึก 20 ชั้น และเปิด **ตา AI** เพื่อให้โค้ชอธิบายตาของ AI ด้วยได้

## ถอดหมากและตั้งหมาก

- **ถอดหมาก** เดินได้ทั้งสองฝ่าย AI วิเคราะห์ทุกตำแหน่ง 2 ทางเลือก แสดงแถบคะแนน แนวต่อ ลูกศรตาที่ดีที่สุด และเกรดของตาที่เพิ่งเดิน กดปุ่ม **∞ ไม่จำกัด** เพื่อให้คิดลึกขึ้นเรื่อย ๆ ได้ (เฉพาะ AI รุ่นเต็ม)
- **ตั้งหมาก** วางหรือลากหมากจากแถบ เลือกฝ่ายที่เดินก่อน แล้วกด **ยืนยัน** เพื่อทดลองเดินตามกติกา
  - ตำแหน่งเก็บอัตโนมัติในเครื่อง
  - คัดลอกหรือเปิดรหัส FEN ได้ (โคน = `s`, เม็ด = `m`, เบี้ยหงาย = `m~` ตามแบบ PyChess)
  - แชร์ตำแหน่งเป็นลิงก์หรือรูปภาพได้

## การนับตามกติกา

ตามกติกาการแข่งขันหมากรุกไทย พ.ศ. 2569 ข้อ ก 5 (ใช้ใน เล่น 2 คน · เล่นกับ AI · ตั้งหมาก):

- **นับศักดิ์กระดาน:** เบี้ยคว่ำหมดแต่ทั้งสองฝ่ายยังมีหมาก ฝ่ายที่เป็นรองกด **ขอนับศักดิ์กระดาน** ได้ แล้วนับ 1–64 ถ้าถึงแล้วยังไม่จน ถือว่าเสมอ
- **นับศักดิ์หมาก:** เมื่อฝ่ายหนึ่งเหลือขุนตัวเดียว ระบบนับให้เอง โดยเริ่มที่จำนวนหมาก + 1 นับไปถึงศักดิ์ของหมากฝ่ายไล่ ดังนี้: เรือคู่ 8 · เรือ 16 · โคนคู่ 22 · โคน 44 · ม้าคู่ 32 · ม้า 64 · เม็ด/เบี้ยหงาย 64
- เสมอด้วย: อับ · เหลือขุนสองตัว · เดินซ้ำตำแหน่งเดิม 3 ครั้ง

# สำหรับผู้พัฒนา

เว็บนี้เป็น **HTML, CSS และ JavaScript แบบ static ล้วน** ไม่มีขั้นตอน build ไม่ใช้ framework ไม่โหลดไลบรารีภายนอก และไม่ต้อง `npm install` เครื่องมือมีแค่ Node.js (สำหรับทดสอบและสคริปต์) กับเว็บเซิร์ฟเวอร์ธรรมดา ส่วน Rust ใช้เฉพาะเมื่อจะสร้างตารางท้ายเกมใหญ่

## เริ่มต้นใน 3 นาที

```bash
git clone https://github.com/natstpt/makrukthai.git
cd makrukthai
python3 -m http.server 8080        # แล้วเปิด http://localhost:8080
```

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เปิดไฟล์ตรง ๆ แบบ `file://` จะโหลด AI และตารางไม่ได้) ส่วน AI รุ่นเต็มต้องใช้ `localhost` หรือ HTTPS

รันทดสอบ (Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจ):

```bash
for f in tests/*.test.cjs; do node "$f" || echo "FAIL $f"; done
```

`tests/rs5-tables.test.cjs` ใช้เวลานานมาก ระหว่างพัฒนาข้ามไปก่อนได้

## AI (Fairy-Stockfish)

| รุ่น | ใช้เมื่อ | ไฟล์ | ทรัพยากร |
| --- | --- | --- | --- |
| เต็ม | สุดยอดเซียน และถอดหมากบนเครื่องที่รองรับ | `engine/` หลายเธรด + SIMD + NNUE `makruk-a8c621e24a8c` | โหลด ~48 MB, หน่วยความจำ ~320 MB, ต้องใช้ SharedArrayBuffer |
| เบา | ระดับอื่นทั้งหมด และเครื่องที่ใช้รุ่นเต็มไม่ได้ | `engine/lite/` เธรดเดียว ไม่ใช้ SIMD | โหลด ~1.4 MB, ใช้ได้กับเบราว์เซอร์แทบทุกตัว |

- GitHub Pages ตั้ง header COOP/COEP เองไม่ได้ จึงใช้ `coi-sw.js` ช่วย
- ถ้ารุ่นเต็มเริ่มไม่สำเร็จ ระบบจะเปลี่ยนไปใช้รุ่นเบาเอง
- ถ้าเบราว์เซอร์ไม่รองรับ WebAssembly จะใช้ AI แบบง่ายใน `makruk-play.js` แทน
- ความลึกและเวลาคิดของแต่ละระดับอยู่ใน `AI_LIMITS` และ `LEVELS` ต้น `editor.js`

## ตารางท้ายเกม (endgame tables)

ตารางเก็บคำตอบของทุกตำแหน่งในท้ายเกมชุดหนึ่ง ว่าต้องใช้กี่ตาจึงจน เมื่อขุนหนีเดินดีที่สุด AI คำใบ้ บทไล่ยาว และหน้าวิเคราะห์ใช้ตารางนี้ทันทีที่เกมเหลือหมากตรงชุด เว็บโหลดเฉพาะไฟล์ที่ตรงกับหมากบนกระดาน

| ชุด | ไฟล์ | สร้างด้วย |
| --- | --- | --- |
| เรือ, เรือคู่ | `tablebase/krk.bin`, `krrk.bin` | `scripts/build-krk.cjs`, `build-krrk.cjs` |
| หมาก 1–2 ตัว (เรือ ม้า โคน เบี้ยหงาย) vs ขุนเดี่ยว | `tablebase/<ชื่อ>.bin` | `scripts/build-endgame-tables.cjs` (~30 นาที) |
| หมาก 3 ตัว vs ขุนเดี่ยว ครบ 20 ชุด และชุดที่ทั้งสองฝ่ายมีหมาก | `tablebase/rs/` | `tools/makruk-tb` (`export`) |
| ชุดใหญ่เกินจะขึ้นเว็บ (เช่น หมาก 6 ตัว 10.6 GB) | `tablebase-local/` บนเครื่องเท่านั้น | `tools/makruk-tb` แล้วเปิดผ่าน `makruk-tb serve` |

- เม็ดกับเบี้ยหงายเดินเหมือนกัน จึงใช้ตารางเดียวกัน
- ตัวสร้าง Rust เร็วกว่าตัว JavaScript หลายสิบเท่า วิธีติดตั้งและคำสั่งอยู่ใน [tools/makruk-tb/README.md](tools/makruk-tb/README.md)
- ตรวจตารางในเครื่องด้วย `scripts/check-local-tables.cjs` และ `scripts/check-local-server.cjs`
- ตารางยังไม่รวมการนับศักดิ์ หน้าถอดหมากจะเทียบจำนวนตากับการนับให้

## ข้อจำกัดที่ควรรู้

- ความคืบหน้าและผลเกมเก็บในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ยังไม่มีบัญชีผู้ใช้ และเปลี่ยนเครื่องแล้วข้อมูลไม่ตามไป
